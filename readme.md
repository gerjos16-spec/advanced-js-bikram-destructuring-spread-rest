# JavaScript avanzado: destructuring, spread y rest

Ejercicios prácticos para aprender a utilizar la destructuración, el operador spread y los parámetros rest en JavaScript.

## Cómo realizar los ejercicios

1. Abre `index.js`.
2. Resuelve allí los ejercicios.
3. Abre `index.html` en el navegador para ejecutar las pruebas.
4. Sube la solución a GitHub e incluye una captura de pantalla de las pruebas.

## Ejercicios

### Destructuración

1. A partir del array `empleados`, extrae el objeto completo de Ana en la variable `ana`.
2. A partir de `empleados`, extrae el correo de Luis en la variable `emailLuis`.
3. Intercambia los valores de las variables `a` y `b` usando destructuración.
4. Extrae `today` y `tomorrow` de `HIGH_TEMPERATURES` en las variables `maximaHoy` y `maximaManana`.

### Spread y rest

5. Implementa `sumEveryOther`, que reciba cualquier cantidad de números y devuelva su suma.
6. Implementa `addOnlyNums`, que reciba cualquier cantidad de valores y sume únicamente los números.
7. Implementa `countTheArgs`, que devuelva la cantidad de argumentos recibidos.
8. Implementa `combineTwoArrays`, que combine dos arrays en uno usando el operador spread.
9. Implementa `onlyUniques`, que devuelva un array con los argumentos únicos, conservando su orden.
10. Implementa `combineAllArrays`, que combine cualquier cantidad de arrays en uno.
11. Implementa `sumAndSquare`, que eleve al cuadrado todos los argumentos numéricos y devuelva la suma de los cuadrados.

## Pruebas

Las pruebas están en `js/index.spec.js` y utilizan Jasmine. Para ejecutarlas, abre `index.html` en un navegador con JavaScript habilitado.
